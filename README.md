# 🤝 Projeto Acolher — Sistema de Gestão de Doações

Sistema web desenvolvido para a **Associação Projeto Acolher**, iniciativa social vinculada ao Centro Evangelista Internacional (CEI), com o objetivo de otimizar o gerenciamento de doações e o controle de estoque de alimentos destinados a pessoas em situação de vulnerabilidade social.

---

## 📋 Sobre o Projeto

O Projeto Acolher surgiu a partir da necessidade de modernizar o processo de controle de doações realizado pela instituição. Antes da implementação do sistema, os registros eram feitos manualmente por meio de cadernos e relatórios físicos, tornando o processo mais suscetível a erros, perdas de informações e dificuldades de consulta.

Como solução, foi desenvolvida uma aplicação web capaz de centralizar o gerenciamento das doações, proporcionando maior organização, segurança e eficiência no controle dos alimentos recebidos e distribuídos.

Além disso, considerando que parte dos usuários possui pouca familiaridade com recursos tecnológicos, o sistema foi projetado com foco em acessibilidade e facilidade de uso.

---

## 🎯 Objetivos

### Objetivo Geral

Desenvolver um sistema web para registrar, organizar e consultar informações relacionadas às doações e ao estoque de alimentos da instituição.

### Objetivos Específicos

- Levantar e documentar os requisitos da instituição.
- Desenvolver funcionalidades de cadastro e consulta de doações.
- Facilitar o controle de estoque dos alimentos recebidos.
- Melhorar a organização e rastreabilidade das informações.
- Reduzir erros operacionais e perda de dados.
- Disponibilizar uma interface simples e acessível aos usuários.

## 🏗️ Arquitetura da Solução

A aplicação foi desenvolvida seguindo o modelo cliente-servidor, utilizando tecnologias modernas para garantir desempenho, escalabilidade e facilidade de manutenção.

### Backend

- Python
- Django
- API REST
- Respostas em formato JSON

### Banco de Dados

- MySQL
- Hospedado no Clever Cloud

### Frontend

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

### Infraestrutura

- Hospedagem da aplicação: Render
- Autenticação nativa do Django
- Gerenciamento de sessões por cookies

### Fluxo da Aplicação

```text
Usuário
   ↓
Frontend (HTML, CSS, JavaScript, Bootstrap)
   ↓
Backend (Django REST)
   ↓
Banco de Dados MySQL (Clever Cloud)
```

## 📖 Desenvolvimento do Projeto

O projeto foi desenvolvido como atividade extensionista da disciplina de **Desenvolvimento Web 3**.

Durante sua execução, a equipe realizou visitas à instituição parceira para compreender suas necessidades e levantar requisitos reais do ambiente de trabalho.

Uma entrevista com os responsáveis pelo Projeto Acolher permitiu identificar os principais desafios enfrentados pela organização, especialmente relacionados ao controle manual das doações e do estoque.

Com base nessas informações, a equipe estruturou a solução e dividiu as atividades entre desenvolvimento backend, frontend e documentação.
